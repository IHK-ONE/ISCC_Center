# ISCC Center
由 Python 实现的一键化批量账号管理、附件下载、提交 flag。并多次优化，提高用户舒适性。

## 页面与功能
主页：点击 ISCC 控制台跳转主页

+ 展示所有账号的解题状态

![](https://cdn.nlark.com/yuque/0/2026/png/35229002/1778402994901-ba7f6821-81b4-43ca-876f-56d729d495b9.png)

账号：

+ 支持批量导入账号
+ 可多选账号进行登入，登入自动更新 session、题目 nonce、题目访问状态
+ 支持账号删除，账号删除时不删除存储的 flag

![](https://cdn.nlark.com/yuque/0/2026/png/35229002/1778078407805-662e958f-0bd5-42fe-a3bb-acd829e001a5.png)

题目：

+ 支持批量刷新题目缓存，默认全选状态下会自动更新题目（包括新上题目）
+ 没有登入时也会自动登入，自动刷新题目访问状态

![](https://cdn.nlark.com/yuque/0/2026/png/35229002/1778078436586-baab78e7-8410-4728-82e5-8cd63906fab4.png)

![](https://cdn.nlark.com/yuque/0/2026/png/35229002/1778078754702-877b7e00-e9e4-4289-87aa-0e00b07ba528.png)

附件：

+ 支持更新附件，附件不会重复下载，共用已有附件
+ 支持下载原始附件

![](https://cdn.nlark.com/yuque/0/2026/png/35229002/1778078849489-2bf74b76-f86e-46bb-a72b-f181bb264d99.png)


提交：

+ 支持 md5 自动匹配提交 flag，会自动匹配题目和用户
+ 支持批量题目提交


配置：

+ 支持跳过 web、pwn 附件下载，需要手动配置（共用靶机）
+ 支持设置代理池，代理池会自动删除不可用代理，也可提前进行测速

![](https://cdn.nlark.com/yuque/0/2026/png/35229002/1778079049056-05111a8f-bbcf-4791-8978-4a3c98b58551.png)
